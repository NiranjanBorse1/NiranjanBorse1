### 🚨 RescueLink — Ongoing

An offline multi-hop distress signaling system designed for disaster zones and remote treks where cellular connectivity may be unavailable.

The system uses a **BLE crowd mesh** for phone-to-phone communication, with **ESP32 LoRa gateways** as a long-range backhaul layer. It includes **CAPR battery-aware routing, SOS prioritization, engineering-mode network visualization, and Trek Mode with automated fall detection**.

**Tech:** Android, Kotlin, BLE, LoRa, ESP32, TFLite, Room, Gradle

**Status:** Currently in development and undergoing multi-phone field validation.
